# Scoped DE/EU Marketstack transport

Ported from the unmerged #334 head `bf84b7ae99b1d291de6b61d1f7ba42ef262c6eb1`, ported and tested on current main `1d56daf897ed7374c6f44c9cdc22faaf1e49b192`. Reuses `quant/engines/market-client.js`; no competing transport, ETF import or production routing change. `https://api.marketstack.com/v2` is fixed. Account entitlement remains observation-specific.

Create one `createSharedBudget` from `scripts/market/marketstack-budget.mjs` for the entire run, then pass it to every `createMarketstackClient`. Each page and retry reserves conservative symbol credits durably before fetch; the same ledger and run ID apply to all selected phases and agents. Damaged/missing state, replay or a mismatched prior ledger hash stop before paid requests.

The selected Consumer development run has explicit user authorization for a **15,000-credit target and 20,000-credit hard cap**, including retries. When the provider does not expose an account remainder, `UNKNOWN_USER_AUTHORIZED_DETERMINISTIC_COUNTER` records that uncertainty without inventing a balance. The immutable lease, completed Actions history and preceding ledger hash are verified before every later phase. The credit allowance is this run's ceiling, not an account remainder. Any proven smaller account bound reduces it. No recurring job is activated.

The default account-bound research mode remains separate: historical run cap ≤10,000, local monthly ceiling 5,000 and 500-credit reserve. It requires private `VERIFIED_ACCOUNT_REMAINDER` or `COMPLETE_ACCOUNT_LEDGER` evidence within 24 hours. A partial ledger or advertised plan is insufficient. The explicitly authorized Consumer mode supersedes that unmerged research default only for this development request; it does not change subscriptions or existing live consumers.

Adapter mappings require `symbol`, `exchange`, `mic`, `isin`, `securityId`, `listingId`, `currency`, `assetType`, `mappingVerified:true`, `currencyVerified:true`, `mappingSource`, `currencySource`. The calling reference/mapping pipeline supplies verified identities; ticker/name matching alone does not. Local preferred equity additionally requires `shareClassVerified:true` and `assetType:"preferred_equity"`. US identity and preferred filters are unchanged.

`getMetadata(id)` first applies the canonical mapping gates, then calls `GET /v2/tickers/{symbol}`. It accepts direct or `data`-wrapped objects, requires an exact returned ticker, rejects a returned conflicting ISIN or instrument class, and requires the selected MIC in `stock_exchange`/`stock_exchanges`. A missing returned ISIN does not prove one: the independently verified mapping remains the basis. Local preferred shares may retain their verified class when metadata labels them generic equity. Currency comes from independently verified listing metadata; this generic ticker response is not a currency-verification source. `has_eod:true` yields coverage `PARTIAL`, not strategy admission; absent flags remain `UNKNOWN`. This method alone neither certifies current quotes/history nor grants publication or real-time rights.

`client.onResponse` may persist credential-redacted original responses, including endpoint, v2, host and retrieval time. It is awaited and persistence failures withhold the result. Keep response bodies, quarantined rows, prices and account evidence private. `marketstack-cache.mjs` uses the existing Tiingo AES-GCM/archive implementation with separate provider magic/KDF domain; Tiingo defaults and ciphertext remain compatible. Persist **ciphertext only** in public Actions caches. Missing/unreadable encrypted caches never prove a fresh account balance.

Provider adjusted fields are observations by default. A global `adjustmentVerified` flag cannot grant admission. A listing-scoped `adjustmentEvidence` requires verified source, from/to and explicit OHLC basis; volume has separate evidence. Invalid bars and duplicates remain explicit anomalies and block technical admission. The returned good subset is not a complete technical series. Latest EOD identity, positive values, calendar date and supplied OHLC are checked; the DE/EU orchestrator retains calendar/freshness as unknown until a verified local calendar and delivery expectation are supplied; this is not current-session certification. Publication remains blocked.

`marketstack-de-eu-preflight.yml` defaults to read-only preflight and performs **zero provider requests** on pull requests or a default dispatch. Its explicit `import_selected` dispatch requires private encrypted inputs and current account evidence before any provider request. Failed attempts are sealed too so credit reservations survive failures; immutable cache keys include run/attempt, cache existence is verified, and the latest dispatch must match restored encrypted state or require fresh account reconciliation. Reruns cannot perform paid calls. There is no schedule. It tests credentials' presence, encryption and private budget evidence; it does not authenticate to Marketstack, import, publish or schedule. No raw dataset or account artifact is uploaded. Public delivery requires the central rights gate and official product builders; this port grants no new display or redistribution right.

Validation: `node --test quant/tests/marketstack-*.test.mjs quant/tests/tiingo2-cache.test.mjs` on Node 22. All transport requests in these tests are injected fakes.

The expanded Consumer run uses the explicit bounded authorization described in [private Actions handoff](../../scripts/marketstack/PRIVATE_ACTIONS_HANDOFF.md): 15,000 target / 20,000 hard cap, shared deterministic counter when account remainder is unavailable. This supersedes the historical 5,000 research default only for this run, does not invent an account balance, and activates no recurring schedule. Five-year EOD retrieval is bounded to two 1,000-row pages per listing; dedicated split/dividend responses are retained separately and cannot certify an unreported MIC or share basis. The compact private Screener projection and detail/chart latest prices use the same Core helper and registered producer. Public delivery remains blocked.

The actual European representative run returned empty dedicated action feeds despite positive dividend observations in EOD. The current v2 documentation names NASDAQ, NYSE, NYSE ARCA, PINK, SHG, OTCQB and BATS for `/splits` and `/dividends`; it does not name the selected EU MICs. The mandatory EU import records this unsupported endpoint scope instead of repeating empty requests per listing. Embedded EOD action and adjusted fields remain private observations, with `actionsComplete:false`; they do not certify adjustment or backtest readiness.
