# Annual SEC facts: isolated certification draft

The adapter certifies source concepts, units, fiscal periods and actual original acceptance timestamps. It does not migrate the Fundamental Core, change a frozen method, promote a current issuer identifier to historical identity, or establish a complete historical PIT universe.

The official [companyfacts bulk](https://www.sec.gov/Archives/edgar/daily-index/xbrl/companyfacts.zip), [submissions bulk](https://www.sec.gov/Archives/edgar/daily-index/bulkdata/submissions.zip) and [SEC API documentation](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) are reachable. An actual original XBRL filing and archival submission header were inspected privately. The adapter produced direct facts with concept, resolved unit, entity context, annual duration, original fiscal-year focus and source hashes. Actual values, issuer identifiers and evidence files remain under the private certification directory.

The raw API acceptance clock can disagree with the original archival header. `ACCEPTANCE-DATETIME` in the original header is normalized from `America/New_York` through the IANA timezone database. API values remain diagnostic. A conflict stays visible as MEDIUM/PIT_PARTIAL; a missing, ambiguous or nonexistent original clock blocks exact acceptance certification. Received byte ranges in a header artifact have an explicit range/hash scope. `availableAt` remains the actual original acceptance; the adapter separately records the first eligible signal session and requires an explicit UTC formation cutoff before facts are supplied to the original selector.

`companyfacts.fy` and `fp` describe the filing's reporting focus and cannot independently label a comparative prior-year fact. Fiscal-year lineage comes from the original current-report DEI focus and a complete annual XBRL context. Comparative restatements and amendments receive their own later acceptance timestamp. The original annual-period dates are retained. A future fiscal-label conflict cannot erase earlier original knowledge; its dated conflict marker blocks decisions only when visible.

PR #481 remains OPEN/BLOCKED. Its audit reader and source concept definitions were inspected as research references. #504 separates annual and TTM labels; it supplies no historical vintage certification. #505's as-reported design is useful, but filing-day granularity and its limited metric scope do not satisfy this contract. #510's primary revenue evidence stage is a useful design reference; no existing decision is silently inherited without its precise accession/build provenance. No branch was merged or Core code copied into main.

The [FASB ASU 2015-01 primary PDF](https://storage.fasb.org/ASU%202015-01.pdf) was downloaded and inspected. Its extraordinary-items change applies to annual periods beginning after the stated effective-date boundary. A fiscal-year label alone does not establish applicability; early adoption is not guessed. Conditional net-income, common-equity, total-debt and EBIT identities require an independent approval record established before measurement. All operands retain concept, unit, period, actual acceptance and source hashes. `OperatingIncomeLoss` never becomes EBIT automatically. Preferred equity and issuance are never assumed zero when missing. Positive common-equity cash issuance can prove a false no-issuance flag; zero cash proceeds cannot prove no issuance, especially when noncash or employee issuance may exist.

The adapter emits original fiscal-period links for the independently reviewed resolver. The original Piotroski implementation cannot consume genuine shifted 52/53-week and leap-year links. Any period-resolution correction belongs to the separate reviewed BUGFIX_VERSION; the original method and its hashes remain unchanged.

The additional `certifyCompanyfactsAnnualPartial` channel avoids requiring original XML for every annual observation. It accepts original response-byte hashes for official API documents or original ZIP entries with a container hash. Only original 10-K facts whose reported end matches that filing's reported end and whose duration spans a full annual period establish first vintages. It claims MEDIUM/PIT_PARTIAL, keeps DEI fiscal-year certification unknown and emits no certified fiscal links. The availability boundary is explicitly the first New York midnight after the official filing day; it is a conservative bound, not an invented actual acceptance timestamp. Both `actualAcceptedAt` and `firstKnownAt` remain unknown. Original archival SIC headers can be supplied separately; current API SIC never supplies historical classification.

Later amendments with unknown replacement scope and comparative value changes produce dated invalidations. The mandatory formation prefilter removes affected keys after the boundary instead of silently retrieving older conflicting observations. The original selector cannot enforce these extra invalidation fields by itself. Consumers must invoke `selectAnnualFactsAtFormation` before supplying rows to an unchanged engine.

The scoped XML parser rejects missing and duplicate context/unit identifiers and undeclared references. It resolves each unit QName in that element's actual namespace scope. Later namespace rebinding or later original fiscal-year claims cannot alter earlier certified source knowledge.

Two actual original annual filings were compared privately, including one before/as 2025. The six revenue/COGS/assets comparisons matched the primary XBRL and accession-bound official companyfacts values, periods and units. This is a focused source viability check; it does not certify identity, all concept combinations or an unseen whole-universe holdout.

The companion JSON contract states exact source concepts, pending derivation conditions and output fields. A successful primary-filing audit is source viability evidence, not a full-universe data or performance certification. Identity, market-equity scope, signal timing and every method-specific required field remain separate admission gates.
