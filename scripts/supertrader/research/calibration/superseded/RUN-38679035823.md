# Pipeline run 38679035823 (freeze V3-8e324a9cd75516cf) - superseded

Outcome: all four numeric calibration methods measured and reconciled; the content-bound re-capture check
passed in every job; the independent numeric review failed R4 (fill price equals the session open) for every
method in both cost modes. Completion: CALIBRATION_INCOMPLETE / NOT_CERTIFIED (review failure, hard stop).
The tournament was skipped by design. No performance numbers were published or read.

Cause (reproduced offline with synthetic data, not with the private data): when the terminal date of a
DATA_QUARANTINE security coincides with an execution session, the calibration engine put a synthetic bar
(open = last close) into the map used for ORDER execution as well as for terminal settlement. A method order
could therefore buy or sell that security on a date for which no source bar exists. The independent review
correctly flagged this; it is a construction defect, not a reviewer defect.

Fix (before any result was inspected): orders execute only against real source bars; the synthetic bar remains
for terminal settlement and marking. R4 stays a hard check. The review additionally reports an informational
split of R4 (fills without a source bar vs price mismatches). Files: portfolio-calibration-v3.mjs,
numeric-review-v3.mjs, regression test in calibration-v3-numeric-review.test.mjs.
The records of this run remain as evidence; a new run produces a new freeze.
