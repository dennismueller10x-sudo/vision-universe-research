Audit date: 2026-10-07. No authenticated/paid API requests made by this reviewer. Current-main Marketstack absence supplied by parent; implementation review is explicitly of the separate unmerged `/workspace/marketstack-reference` PR #461 tree, not an assertion about production/main.

## Confirmed findings

1. **Discovery endpoint omitted, rather than first-page truncation proved.** Reference adapter has no search or exchange-ticker listing. Current V2 global directory is `/tickerslist`, with `search` company-or-symbol, optional `exchange` MIC, `limit` 1–1000 (default100), `offset`. `/exchanges/{mic}/tickers` supports name/symbol search plus limit/offset; its envelope is `pagination` plus `data.tickers[]`. V2 Swagger does **not** list a global `/tickers` endpoint. `/tickers/{symbol}` is exact single metadata. Client generic paginate supports `data[]` and `data.tickers[]`, but it is never invoked for discovery by adapter.

2. **Earlier negative metadata status is narrower than coverage absence.** `scripts/marketstack/probe-missing-identities.mjs:46–61,109` freezes candidates from explicit reference or official local ticker + `.DE`, then only requests `/tickers/{symbol}`. There is no name search, documented `/tickerslist`, exchange list or downloadable provider directory search. `identityResolution()` can label exhausted candidates `NOT_SUPPORTED`; that is not proof Marketstack cannot serve another documented symbol/route.

3. **Reference contract is incomplete.** Existing adapter uses `/eod`, `/eod/latest`, `/intraday`, `/intraday/latest`, `/stockprice`, `/tickers/{symbol}`, `/splits`, `/dividends`. It omits `/tickerslist`, `/tickerinfo`, `/exchanges`, `/exchanges/{mic}`, `/exchanges/{mic}/tickers`, `/indexlist`, `/indexinfo`, `/etflist`, `/etfholdings`, currencies/timezones and commodities endpoints. Equivalent ticker/exchange-scoped price variants are documented but need not all be used if global equivalent route is correct. `getMetadata()` uses exact ticker metadata, not richer `/tickerinfo` company information.

4. **ETF support absent in reference adapter.** `assetType()` accepts equity/preferred equity only; `resolveMapping()` rejects ETF listings. There are no ETF list/holdings adapter methods. Thus a prior ETF materialization result does not come from this reference adapter's contract and cannot establish its pagination completeness.

5. **ETF response is not generic data[] pagination.** `/etfholdings` documents ticker(required), optional date_from/date_to, limit/offset. Schema is `basics` and `output`, `output.attributes`, `output.signature`, `output.holdings[].investment_security`. It has no advertised top-level pagination/total. `/etflist` DOES have `pagination` + `data[{ticker}]`. Each endpoint is explicitly a 20-call multiplier. Generic `client.paginate()` without custom extractor would reject holdings. Even with an extractor, an absence of pagination and a short array alone cannot prove full holdings: actual offset/limit effects must be measured.

6. **ETF known fields and limits.** `basics`: fund_name,file_number,cik,reg_lei. `output.attributes`: series_name,series_id,series_lei,ticker,isin,date_report_period,end_report_period,final_filing. Investment-security fields: lei,isin,name,cusip,title,units,balance,currency,value_usd,percent_value,asset_category,cash_collateral,non_cash_collateral,fair_value_level,invested_country,issuer_category,loan_by_fund,payoff_profile,restricted_sec. No constituent ticker, reported total holdings, AUM, TER/OCF, benchmark, domicile, UCITS flag, distribution policy, replication, NAV, inception, fund currency, sector allocation or country allocation documented here. Country can be represented per holding in invested_country. Schema absence is not proof actual raw fields cannot extend schema. SEC CIK/file/series fields indicate filing data; do not classify report-period data as daily issuer holdings without checking as-of.

7. **Realtime routes and semantics differ.** `/intraday` explicitly serves US IEX tickers. It supplies derived real-time reference price `marketstack_last`; docs say bid/ask/last-related fields have been null without extra IEX entitlement since 2025-02-01. Intervals are 1min,5min,10min,15min,30min,1hour,3hour,6hour,12hour,24hour. `/stockprice` separately claims worldwide coverage incl NYSE,NASDAQ,LSE and has required ticker, optional exchange MIC. Schema is data[] with exchange_code,exchange_name,country,ticker,price,currency,trade_last; price and trade timestamp are **last known**. It contains no freshness guarantee, quote-delay classification or update timestamp. Europe availability and live/delayed result require account raw response and timestamp comparison; US-only intraday does not imply US-only stockprice.

8. **Metadata fields lost in reference normalization.** `/tickers/{symbol}` documented symbol,name,isin,cik,cusip,ein_employer_id,lei,series_id,item_type,sector,industry,sic_code,sic_name,stock_exchange. Adapter returns name,isin,providerSymbol,exchange,currency,assetType,coverage only. Identifiers/company descriptors/exchange country,country_code,city,operating_mic,status are dropped from normalized metadata. `/tickerinfo` can add IPO/founding dates, reporting_currency, exchanges, address, website, description, executives; not currently called. Missing reporting_currency is not proof no trading-currency field exists elsewhere and should not be substituted for quote currency.

9. **Adjusted OHLC handling is deliberate transform, not lost raw evidence if capture enabled.** normalizeBar preserves adjustedOpen/High/Low,adjustedVolume,splitFactor,dividend; adjustedClose is null unless independent listing/window adjustment evidence verifies it, with observed adj_close retained in adjustmentObservation.close. Raw open/high/low/close/volume are retained. EOD raw symbol/name/exchange/exchange_code/asset_type/price_currency not all survive as original keys, though symbol/currency/type/venue live in mapping/series/provenance. Raw responses only persist through supplied onResponse hook, not unconditionally; ingestion opts may provide it. Preserve raw separately before concluding normalization loss.

10. **Minor documented error mapping defect.** Getting Started documents error.code `404_not_found`. Client only recognizes `not_found_error`,`data_not_available`, returning generic providerError for `404_not_found`. Status404 in identity script still maps unsupported candidate, but client consumers cannot reliably distinguish resource unavailable from other provider errors. `invalid_api_function` should remain endpoint/configuration defect, not coverage proof.

11. **Action scope is separate.** Dedicated splits/dividends docs list NASDAQ,NYSE,NYSE ARCA,PINK,SHG,OTCQB,BATS. Their schemas omit MIC,currency,ISIN; splits has split_factor,stock_split,date,symbol and dividends has dividend,payment_date,record_date,declaration_date,distr_freq,date,symbol. Reference correctly does not assert EU action completeness. Global EOD docs describe adjusted corporate-action values using CRSP methodology; empirical listing/date windows still needed, so dedicated-action lack cannot invalidate global EOD by itself.

12. **Docs contain contradictions.** Quickstart says `/v2/eod/symbols` and interval `1h`, contradicting its own examples and current Swagger route/enum (`/v2/eod?symbols=...`, `1hour`). Getting Started uses singular `symbol` in generic prose although actual EOD/intraday parameters are `symbols`. `/stockprice` prose mentions bid/ask/volume but schema lacks them. `/etflist` prose mentions name/exchange but schema only ticker. Treat current Swagger+measured raw as contract evidence and explicitly preserve inconsistencies.

## Professional capability matrix from docs only

- EOD + history + adjusted OHLC/volume: `/eod`, `/eod/latest`, `/eod/{date}`, ticker/exchange variants; optional symbols/exchange/date bounds/sort/limit/offset; global documented coverage; Professional advertised, account entitlement still empirically verified by parent.
- Splits/dividends: `/splits`,`/dividends`, ticker variants; symbols/date bounds/sort/limit/offset; named US/other venues as above; advertised Professional.
- Stock info: `/tickerslist`,`/tickers/{symbol}`,`/tickerinfo`; global directory versus richer company endpoint; Professional advertised basic info, richer endpoint entitlement requires real account check.
- Exchange info: `/exchanges`,`/exchanges/{mic}`, `/exchanges/{mic}/tickers`; ISO MIC scope; 2,700+ exchange metadata does not mean 2,700+ price feeds.
- Currencies/timezones: `/currencies`,`/timezones`; reference datasets, limit/offset; Professional advertised.
- HTTPS/commercial/support: transport/licensing/support features, not data endpoints. Price payloads cannot establish a commercial-use license by themselves.
- IEX intraday/Real-Time Updates: `/intraday` and latest/date/scoped variants; IEX US, intervals <15min advertised Professional real-time updates.
- Real-time Stock Market Prices: `/stockprice`; worldwide advertised; actual European fresh/delayed listing support requires timestamp observations.
- Index: `/indexlist` limit/offset, `/indexinfo` index required; global advertised; prices versus components per raw.
- Bonds: `/bondlist` country/limit/offset, `/bond` country required; government benchmarks; advertised.
- ETF holdings: `/etflist` ticker/status/date/limit/offset, `/etfholdings` ticker/date/limit/offset; schema uses SEC filing identities; UCITS breadth unknown pending raw.
- Commodities: `/commodities` commodity_name; `/commoditieshistory` commodity_name/date/frequency; 70+ commodity universe, <=1request/min; Professional advertised. History duration varies by commodity.

## Review disposition

Confirmed VU/reference gaps: directory endpoint omission, narrow candidate resolver, absent ETF adapter contract, metadata field omission, documented error-code omission. No evidence from this docs-only review proves provider Europe realtime support, provider/API website parity, ETF holdings completeness or a current-account entitlement. No evidence proves existing discovery lost pages because it never performed directory paging; newly introduced route must nevertheless be tested across pages. Do not merge a broad Europa or Quant feature branch as a shortcut: keep connector-only corrections isolated as requested.
