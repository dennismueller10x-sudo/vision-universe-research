## Belege

- **PIT_INDUSTRY_GROUPS:** sic-peer-taxonomy-v1.json: snapshotMode CURRENT_ONLY, historicalClassificationAvailable false, backtestEligible false; the licensed provider supplies no sector field in the current plan (docs/TIINGO_COMMERCIAL_SCALE_PHASE1.md; quant/data/market/factors sector SOURCE_MISSING)
  - Verfügbarkeitsprüfung 2026-10-20 (about 20 (4 issuers: submissions JSON, 12 filing headers, 1 Financial Statement Data Sets quarter)):
    - data.sec.gov/submissions/CIK##########.json carries only the CURRENT sic (no history)
    - every filing header (Archives/edgar/data/<cik>/<accession>.hdr.sgml) records the SIC at filing time: AMAZON COM INC 10-K405 1998-03-30 SIC 2731, 10-K 2012 and 2026 SIC 5961 (current) - historical SIC differs from today and is recoverable; Apple 3571, Netflix 7841, IBM 3570 unchanged across their first / middle / last 10-K
    - headers carry ACCEPTANCE-DATETIME in the 2003+ samples and none in the 1994 / 1998 samples (there the filing date is the earliest-known time, day granularity)
    - SEC Financial Statement Data Sets (www.sec.gov/files/dera/data/financial-statement-data-sets/<yyyy>q<n>.zip, quarterly from 2009q2) sub.txt has per XBRL filing: adsh, cik, sic, form, filed, accepted - a bulk point-in-time SIC series for 10-K / 10-Q filers covering the snapshot window 2016-2026 (one quarter about 100 MB zipped)
    - Grenze: SIC is the SEC staff classification of the registrant (Standard Industrial Classification, 4 digits); it is not a correlation measure and not an investment industry-group scheme
    - Grenze: only SEC registrants with filings: ETFs, ADRs filing 20-F (FSDS covers 20-F XBRL only from about 2017), and listings without a CIK mapping get no group (groupsOf -> null, counted, run labelled ENFORCED_PARTIAL_GROUP_COVERAGE)
    - Grenze: before the first filing seen in the window the group is unknown (no back-fill)
- **MARKET_BREADTH_HISTORY:** the file states breadth is not reconstructable backwards (survivorship); NYSE A/D is not in the repository (docs/SUPERTRADER_STRATEGY_COVERAGE_MATRIX.md WEIN-CTX-MI / -HL)
